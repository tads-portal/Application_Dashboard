Backup & Restore

Full JSON backup of all local TADS data on this device

Export Backup

Downloads a single JSON file containing all projects, field configuration, and application settings. Keep this file somewhere safe — it is the only way to move your data to another computer or recover it if this browser's storage is cleared.

Restore Backup

Restoring replaces all current local data with the contents of the backup file. A safety backup of your current data is downloaded automatically before anything is changed.
